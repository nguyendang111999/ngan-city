# Nhạc / ảnh meme tuỳ chọn

Thư mục này dành cho file bạn tự thêm (đã nằm trong `.gitignore`). Khai báo trong `src/content.js`:

- `music.title` / `music.finale` — nhạc nền màn hình chờ và thiệp cuối (mp3/m4a/ogg).
- `music.m2` — nhạc cho phi vụ "Múa Quạt": `{ src, bpm, offset }`
  (`offset` = số giây từ đầu file tới phách đầu tiên).
- `tocTruong.avatar` — ảnh avatar cho "Tộc trưởng" trong điện thoại.

Không có file nào thì game dùng nhạc tự tổng hợp và icon mặc định.
Chỉ dùng cho quà tặng riêng tư; đừng đăng các file có bản quyền lên chỗ công khai.
